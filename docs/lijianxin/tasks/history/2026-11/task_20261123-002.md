## 遗留项

- 需用户手动执行迁移脚本，并在 server/.env 填写 TENCENT_MAP_KEY
- 未联网实测腾讯接口（无 Key），需用真实 Key 联调
- 部署在反向代理后需配置 app.set('trust proxy')，否则 IP 兜底取到代理内网 IP 会提示手动选城市
- 新城市当天无推荐记录时仍显示「生成失败/重试」，后续可在 setUserRegion 后按需生成
- 微信小程序仍需 requiredPrivateInfos: ["getLocation"] 与 request 合法域名（腾讯接口仅服务端调用，无需配置）
