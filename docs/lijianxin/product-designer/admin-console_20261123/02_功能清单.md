## 实现顺序建议

1. **基础层**：D3、D4、D5（密钥、CORS、两张新表）→ F1 → F8.2。其余所有功能都依赖这一层。
2. **P1 功能**：F2、F3、F4、F5 可并行。F2.4 依赖 D2，F4.3 依赖 D1，F5.3 与 F5.5 依赖 D6。F8.1、F8.3 与上述高危功能同步交付。
3. **P2 功能**：F6、F7、F2.5、F3.6。
4. **P3 功能**：F9、F8.4、（F3.7 已确认不实施）。
